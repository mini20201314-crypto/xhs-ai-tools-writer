# 六维质检清单（AI 工具笔记）

每维 1–5 分。≤2 必须改。

## 1. 关键词 / 搜索

- [ ] 标题或首句出现核心工具名 / 场景词  
- [ ] 正文自然重复 2–3 次核心词（不堆砌）  
- [ ] 标签与正文一致，无无关热搜硬贴  

**扣分：** 全文不提工具名；标签 10 个全是热搜无关词  

## 2. 标题 / 首段钩子

- [ ] 标题 ≤20 字且留悬念  
- [ ] 命中张力 ≥2（数字/反差/冲突/结果/时间/悬念）  
- [ ] 首 2 行能让目标读者停下刷  

**扣分：** 标题已讲完答案；开头「大家好我是 xxx」超 2 行  

## 3. 合规风险

- [ ] 无违禁绝对化（见 forbidden.md）  
- [ ] 无虚假功效 / 虚假收益  
- [ ] 对比公平，不造谣竞品  
- [ ] 涉及价格/限额写清「以官网为准」或注明时间  

**扣分：** 稳赚、官方认证（虚构）、贬低竞品无依据  

## 4. 商业化 / 软广感

- [ ] 像分享不像广告  
- [ ] 利益相关若存在需一句说明  
- [ ] CTA 最多 1 个，且轻（「你用的是哪个」优于「速冲链接」）  

**扣分：** 全文催单；连续安利无踩坑  

## 5. 互动触发

- [ ] 文末有具体问题（二选一/踩过哪个坑）  
- [ ] 有可讨论分歧点或选择点  
- [ ] 有「收藏动机」（清单/步骤/设置项）  

**扣分：** 无提问；纯通稿无观点  

## 6. 结构节奏

- [ ] 短段，扫读友好  
- [ ] emoji ≤8，不连续刷  
- [ ] 干货占比 > 情绪注水  
- [ ] 总字数达标  

**扣分：** 大段落墙；emoji 烟花；注水超过干货
