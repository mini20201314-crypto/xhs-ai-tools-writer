# 糟粕与风险黑名单

## 写作糟粕（本 skill 禁止）

| 糟粕 | 为何丢 | 替代 |
|------|--------|------|
| 强制 ≥5 emoji | 廉价、像营销号 | ≤8 且有语义 |
| 万能「家人们谁懂啊」开头 | 无信息 | 场景痛点开场 |
| 编造月入/涨粉数据 | 信任与合规风险 | 只写可核实体验 |
| 标题说完答案 | 降低点击 | 悬念+痛点 |
| 无关热词标签 | 伤权重、像spam | 相关长尾 |
| 厂商新闻稿腔 | 不转化 | 口语+具体结果 |
| 自动发帖流程 | 账号与合规风险 | 人审后自贴 |
| 美妆公式硬套 AI | 违和 | 用本库 T- 公式 |

## 表达风险词（出现则改写或删）

- 100%、永久、第一、唯一、国家级、官方指定（无资质时）  
- 稳赚、保收益、躺赚、日入、月入 X 万（无真实可证时）  
- 根治、秒杀、吊打全网（攻击性绝对化）  
- 限时、仅剩（虚假稀缺）  

## 对比红线

- 不捏造竞品故障/下架/隐私丑闻  
- 参数对比注明版本与日期  
- 「我觉得 A 更好」必须给场景条件  

## 素材红线

- 不复制他人笔记大段原文  
- 不使用未授权截图中的隐私信息  
- 不确定的功能写「以当前版本为准」
