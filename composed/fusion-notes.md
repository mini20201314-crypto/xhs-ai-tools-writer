# 融合决策记录

## 垂直方向（已锁定）

**AI 工具真实测评 + 场景干货**

- 受众：想用 AI 提效的职场人 / 开发者 / 自媒体 / 学生
- 内容：ChatGPT、Claude、Cursor、Midjourney、效率插件等
- 语气：真实体验、可复现步骤、少鸡汤、不装专家唬人
- 不做：美妆穿搭母婴泛模板、纯割韭菜话术、无证据「月入X万」

## 为什么选这个方向

工作区大量 GPT / 渠道 / 工具相关项目，素材与认知优势在「AI 工具」，
比泛运营模板更容易做出差异化账号。

## 精华清单（写入成品 skill）

1. **公式匹配标题**（dbs-xhs-title）：每个标题可追溯公式类型，非乱写
2. **字数硬限制**（write-xiaohongshu）：标题≤20字，正文≤1000字
3. **先研究再写**：先定人群痛点/对比点/可验证结果，再动笔
4. **转化文案原则**（copywriting）：具体利益、用户语言、不编造数据
5. **六维自检**（note-analyzer）：关键词、标题钩子、风险词、软广感、互动点、结构节奏
6. **轻 emoji + 5~10 标签**（xhs-note-creator 精简版）

## 糟粕清单（明确禁止）

1. 强制刷 emoji（如「至少5个不重复emoji」）
2. 自动发布 / 依赖未审计 MCP 登录态
3. 编造使用数据、评价、对比结果
4. 硬广密堆链接与绝对化承诺（「100%」「稳赚」）
5. 把美妆/母婴爆款句式硬套到 AI 工具
6. 标题说完答案（无点击动机）
7. 标签堆砌无关热词骗流量
